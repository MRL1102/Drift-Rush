# Drift Rush

一个无需安装依赖、可直接在浏览器中运行的 HTML5 俯视角漂移竞速小游戏。玩家要在 60 秒内按顺序穿越赛道检查点，并以连续漂移获取更高分数。

## 运行方法

1. 直接双击 `index.html`，使用现代浏览器打开；或在当前目录启动任意简单的静态文件服务器。
2. 点击“开始竞速”。

项目只包含原生前端文件：

- `index.html`：页面结构、起始页与结算页。
- `style.css`：自适应街机风格界面。
- `game.js`：Canvas 绘制、车辆物理、氮气、碰撞、计分和输入处理。

## 操作方式

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 倒车、减速 |
| `A` / `←` | 左转 |
| `D` / `→` | 右转 |
| `空格 + 转向` | 在具有一定速度时进入漂移 |
| `Shift` | 消耗氮气，触发极速爆发 |

## 玩法与计分

- 每局时长为 60 秒。
- 粉色光门为下一个目标检查点，必须依编号顺序通过；每个检查点均会得分，完成一轮额外奖励 600 分。
- 按住空格并转向会让赛车尾部打滑。漂移持续越久，Combo 倍率越高（最高 x8），松开漂移后结算本次漂移银行分数。
- 漂移会积累氮气；穿过检查点时保持漂移可获得“Drift Gate”额外分数和氮气奖励。
- 赛道上的青色能量芯片会补充 28% 氮气并奖励积分，拾取后会在数秒内重新生成。
- 按住 `Shift` 消耗氮气以突破常规极速，获得火焰尾焰、速度线和轻微震屏反馈。
- 撞到赛道边界会反弹、减速并清空尚未结算的漂移分数与连击。
- 时间结束后显示总分、最高 Combo 和通过的检查点数；可立即重新开始。

## 设计思路

游戏采用固定的 1280×720 逻辑 Canvas，由 CSS 等比例缩放以适配常见电脑屏幕。赛道由外部与内部圆角矩形构成闭环：赛车采样点离开两者之间的道路区域即视为撞墙。赛车速度使用二维向量保存，前向速度提供惯性，横向速度在普通驾驶时快速衰减、在漂移时缓慢衰减，从而形成可控的甩尾效果。新增的氮气循环将漂移、检查点与能量芯片关联成风险奖励玩法；漂移痕迹、烟尘、速度线与爆发尾焰均为短生命周期 Canvas 粒子，不依赖图片资源。最高分会保存到浏览器本地。

## 后续可优化方向

- 增加圈速、幽灵回放、音效与多条赛道。
- 按设备类型加入触摸屏虚拟方向盘。
- 丰富车辆属性、AI 对手和本地最高分记录。
